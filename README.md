# Ecommerce Sales & Customer Insights Analysis

## Project Overview
This project focuses on analyzing ecommerce sales data to uncover valuable business insights related to revenue, customer behavior, product performance, discounts, and sales trends.

The analysis was performed using Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn inside a Jupyter Notebook environment.

---

## Objectives
- Clean and preprocess ecommerce sales data
- Analyze revenue and sales performance
- Identify top-performing products and categories
- Evaluate the impact of discounts on revenue
- Analyze customer ratings and order behavior
- Discover monthly sales trends
- Generate business recommendations from data insights

---

## Technologies Used
- Python
- Pandas

- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Key Analysis Performed
### Data Cleaning
- Handled missing values
- Removed duplicates
- Converted data types
- Created calculated columns

### Exploratory Data Analysis (EDA)
- Revenue analysis
- Monthly sales trend analysis
- Category-wise performance
- Product-wise sales analysis
- Customer rating analysis
- Discount impact analysis

---

## Key Business Insights
- Electronics category generated the highest revenue
- Heavy discounting significantly reduced net revenue
- Average customer satisfaction was moderate
- Sales showed seasonal trends during specific months
- A small number of products contributed heavily to total sales

---

## Business Recommendations
- Optimize discount strategies
- Improve customer satisfaction
- Focus marketing on high-performing categories
- Build customer loyalty programs
- Improve inventory planning during peak seasons
